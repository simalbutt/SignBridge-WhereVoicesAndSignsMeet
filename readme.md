# SignBridge – Where Voices and Signs Meet

---

## Overview
SignBridge is an inclusive e-learning platform designed for deaf and mute students, inspired by Google Classroom. It allows teachers to create classes, upload lecture materials (text, PDFs, documents, and videos), and post announcements, while students can view content, add comments, and ask questions.

Lecture videos include text captions and a sign language avatar that translates content into sign language. Students can submit queries through text or by uploading or recording sign language videos, which are automatically translated into text for teachers, enabling seamless two-way communication.

---

## Features
- Virtual classroom management for teachers  
- Upload and access lecture materials (text, PDFs, documents, videos)  
- Video captions with sign language avatar translation  
- Student interaction via text and sign language video comments  
- Sign language to text translation for teacher accessibility  

---

## Tech Stack
- **Backend:** Django & Django REST Framework (DRF)  
- **Frontend:** React.js  
- **Database:** PostgreSQL  

---

## Purpose
The goal of SignBridge is to bridge the communication gap between teachers and deaf or mute students by integrating accessibility-focused and AI-driven technologies into modern online education.
